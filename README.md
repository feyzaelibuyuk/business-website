# Fazlı Elektrik Aydınlatma

İstanbul ve çevresinde elektrik ve aydınlatma hizmetleri sunan işletmenin web sitesi.

Canlı site: https://fazlielektrikaydinlatma.com.tr

## Özellikler

- Mobil uyumlu gezinme menüsü
- Açık ve koyu tema
- Fotoğraf galerisi, kaydırma ve yakınlaştırma
- Telefon, harita ve yol tarifi bağlantıları
- Site haritası ve robots.txt

## Yerel kullanım

Derleme veya paket kurulumu gerekmez. `index.html` dosyasını tarayıcıda açın.

## Yayınlama

Netlify üzerinde yayınlanabilir. Yayın klasörü, `index.html` dosyasının bulunduğu proje köküdür.
